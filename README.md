# Python-Questions
Tushar Soni Reg No:25BCE10353




This project consists of a comprehensive collection of mathematical and number-theoretic functions written in Python, each designed to handle a specific computational or classification task. The codebase covers a wide range of topics, including basic operations such as calculating the factorial of a number and checking if a number is a palindrome, as well as more advanced tasks like determining if a number is abundant, deficient, or falls into specialized classifications like Harshad, automorphic, pronic, or highly composite numbers. Functions for extracting prime factors, counting unique primes, and testing for properties like prime powers, Mersenne primes, and twin primes offer a detailed toolkit for exploring integer properties. Advanced algorithms such as Miller-Rabin probabilistic prime testing and Pollard’s Rho factorization are also included, providing efficient methods for handling large numbers. Modular arithmetic is well-supported through functions for modular exponentiation, modular inverse, the Chinese Remainder Theorem, and quadratic residue checks, making the suite useful for cryptographic and algorithmic applications. For sequence analysis, generators for Fibonacci primes, Lucas numbers, perfect powers, and polygonal numbers are available, alongside functions for calculating Collatz sequence lengths and partition numbers. All functions feature clear docstrings and logical structures, encouraging readability and reusability. This project can serve as an educational resource, a toolbox for solving Olympiad-style or computational number theory problems, or a reference for implementing foundational algorithms in Python. Each utility has been crafted for clarity, correctness, and ease of integration into larger software projects, following principles of technical documentation such as logical flow, conciseness, and clear separation of function responsibilities
